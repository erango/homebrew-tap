# erango/homebrew-tap

Homebrew tap for my apps and tools.

| | Install | |
|---|---|---|
| [Monitor Glue](https://github.com/erango/monitor-glue) | `brew install --cask erango/tap/monitor-glue` | Puts your windows back on the right monitor when you reconnect it |
| [T1K](https://erango.github.io/t1k/) | `brew install --cask erango/tap/t1k` | Terminal for running many coding-agent tabs at once |
| [Kompass](https://github.com/erango/kompass) | `brew install --cask erango/tap/kompass` | Kubernetes desktop app |
| ccfind | `brew install erango/tap/ccfind` | |
